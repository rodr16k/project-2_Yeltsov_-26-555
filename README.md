# Primitive DB  
Минималистичная база данных, работающая из терминала  

## Требования:  
* **Python** 3.10 и выше;
* Менеджер пакетов **uv**.  

## Установка:  
Чтобы установить проект и запускать из любой папки в терминале с помощью команды `database`, выполните следующие шаги: 
1. Клонируйте репозиторий и перейдите в папку проекта:  
    ```bash
    git clone https://github.com/rodr16k/project-2_Yeltsov_-26-555.git  
    cd primitive_db
    ```
2. Установите пакет глобально в систему:
   ```bash
   uv tool install .
   ```
## Использование:  
```database```
## Управление таблицами: 
*    **create_tables <имя_таблицы> <столбец1:тип> <столбец2:тип>** - создать таблицу,
*    **list_tables** - показать таблицы,
*    **drop_tables** <имя_таблицы> - удалить таблицу,

## Операции с данными:
*    **insert into <имя_таблицы> values (<значение1>, <значение2>, ...)** - создать запись.
*    **select from <имя_таблицы> where <столбец> = <значение>** - прочитать записи по условию.
*    **select from <имя_таблицы>** - прочитать все записи.
*    **update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец> = <значение>** - обновить запись.
*    **delete from <имя_таблицы> where <столбец> = <значение>** - удалить запись.
*    **info <имя_таблицы>** - вывести информацию о таблице.


*    **exit** - выход из программы
*    **help**- справочная информация

## Пример использования:  
[![asciicast](https://asciinema.org/a/e6hAstPQ98A9Vtww.svg)](https://asciinema.org/a/e6hAstPQ98A9Vtww)

* **Создание таблицы:**
  ```text
  Введите команду: create_table users name:str age:int
  Таблица users создана.
  ```
* **Добавление строки:**
  ```text
  Введите команду: insert into users values ('John', 27)
  Строка добавлена
  ```
* **Выбор значений из таблицы:**
  ```text
  Введите команду: select from users
  +----+------+-----+
  | ID | name | age |
  +----+------+-----+
  | 0  | John |  27 |
  +----+------+-----+
  ```
* **Удаление строки:**
  ```text
  Введите команду: delete from users where age = 27
  Удалено 1 строк из таблицы users
  ```
* **Удаление таблицы:**
  ```text
  Введите команду: drop_table users
  Таблица users удалена.
  ```
* **Выход:**
  ```text
  Введите команду: exit
  ```
