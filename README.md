# Primitive DB  
Минималистичная база данных, работающая из терминала  

## Требования:  
* **Python** 3.10 и выше;
* Менеджер пакетов **uv**.  

## Установка:  
Чтобы установить проект и запускать из любой папки в терминале с помощью команды `database`, выполните следующие шаги: 
1. Клонируйте репозиторий и перейдите в папку проекта:  
    ```bash
    git clone https://github.com/rodr16k/project-2_Yeltsov_-26-555.git  
    cd primitive_db
    ```
2. Установите пакет глобально в систему:
   ```bash
   uv tool install .
   ```
## Использование:  
```database```
## Управление таблицами: 
*    **create_tables <имя_таблицы> <столбец1:тип> <столбец2:тип>** - создать таблицу,
*    **list_tables** - показать таблицы,
*    **drop_tables** <имя_таблицы> - удалить таблицу,
*    **exit** - выйти из программы,
*    **help** - справочная информация.

## Пример использования:  
[![asciicast](https://asciinema.org/a/Y1HfFC5y7NqGoIAL.svg)](https://asciinema.org/a/Y1HfFC5y7NqGoIAL)

* **Создание таблицы:**
  ```text
  Введите команду: create_table users id:int name:str
  ```
* **Просмотр списка таблиц:**
  ```text
  Введите команду: list_tables
  ```
* **Удаление таблицы:**
  ```text
  Введите команду: drop_table users
  ```
* **Выход:**
  ```text
  Введите команду: exit
  ```

## Операции с данными

**Функции:**
```text
<command> insert into <имя_таблицы> values (<значение1>, <значение2>, ...) - создать запись.
<command> select from <имя_таблицы> where <столбец> = <значение> - прочитать записи по условию.
<command> select from <имя_таблицы> - прочитать все записи.
<command> update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия> - обновить запись.
<command> delete from <имя_таблицы> where <столбец> = <значение> - удалить запись.
<command> info <имя_таблицы> - вывести информацию о таблице.
<command> exit - выход из программы
<command> help- справочная информация
```


## Удаление пакета:
